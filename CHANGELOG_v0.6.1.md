# SKYLINE v0.6.1 — Real Data & Liveries

- FR24 officiel prioritaire sur le globe et autour des hubs via `FR24_API_TOKEN`.
- OpenSky fallback automatique si FR24 indisponible.
- cache FR24 court et configurable pour limiter les crédits et la RAM.
- opérateur/immatriculation/type/origine/destination exposés dans l'inspecteur trafic.
- marqueurs de trafic colorés selon une bibliothèque de compagnies lorsque l'opérateur est reconnu.
- 22 presets de livrées de compagnies réelles dans le Livery Studio.
- application en un clic puis personnalisation libre.
- endpoint `/api/providers/status` pour vérifier les sources externes.
- aucune clé API ni secret embarqué dans le ZIP.
